# UX-Rundgang 11.09.2026 (Demo-Server, alle Rollen)

Drei Rundgänge (Admin, Berufsbildner, Lernende) auf der Demo-Instanz, hell/dunkel/390 px, Befehlspalette.
Screenshots: `~/tools/out/rundgang/{admin,berufsbildner,lernende}/`.

## Sofort behoben (Commit df09215 bzw. Folgecommit)
- `/suche` im Browser zeigte rohes JSON → leitet ohne `Accept: application/json` zur Übersicht
- Seitentitel «Admin: Feedback» → «Feedback»
- Hinweis «Server aus .env» auf Betrieb → «Vorgabe der Installation»
- Benutzername mit Punkt (`vorname.nachname`) wurde abgelehnt → Punkt, Bindestrich, Unterstrich erlaubt (überall gleiche Regel)
- «Noch keine Sicherung» in Rot → neutral; rot nur bei Fehler oder Sicherung älter als zwei Tage
- 403-Seite zeigte «This action is unauthorized.» → immer deutscher Text, ausser eigenen Meldungen
- Frequenz-Umschalter auf «Benachrichtigungen» ohne Markierung → war ein alter Build während des Rundgangs; mit aktuellem Build korrekt
